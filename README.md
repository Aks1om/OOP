# OOP — практические работы

Задания разложены независимо: у каждого практического задания свой пакет, `Main`/тестовый класс запускается отдельно, а сущности находятся в собственных Java-файлах.

## Практические

| Практическая | Задания | Каталог | Состояние |
|---|---|---|---|
| ПР1, часть 1 | №3 массив и среднее; №4 ввод массива; №5 аргументы командной строки; №6 гармонический ряд; №7 факториал | `pr1/task*/` | Реализованные задания разложены по пакетам. №1–2 и №8 организационные. |
| ПР2 (в PDF «ПР1 часть 2») | `Author` и `Ball` | `pr2/author/`, `pr2/ball/` | Модель и запускаемый тест разделены. |
| ПР3 (в PDF «ПР1 часть 3») | Фигуры; движущиеся объекты | `pr3/shapes/`, `pr3/movable/` | Реализованы классы и демонстрационные `Main`. |
| ПР4 (в PDF «ПР1 часть 4») | Времена года, ателье, интернет-магазин, компьютер | `pr4/task1/`–`pr4/task4/` | Реализовано по условиям, классы и `Main` разнесены по файлам. |
| ПР4.1 | Наследование и дополнительные задачи | `pr4.java` | Сохранён исходный черновик ПР4.1, эта работа отдельно от ПР4. |

В исходных именах PDF «ПР1 часть 2/3/4» — это материалы следующих практических (ПР2/ПР3/ПР4), а не продолжение ПР1.

## Сборка и запуск

Из корня репозитория:

```sh
javac -d out $(find pr1 pr2 pr3 pr4 -name '*.java')
java -cp out pr1.task3.Task3ArrayInit
java -cp out pr1.task4.Task4ArrayInput
java -cp out pr1.task5.Task5CommandLine аргумент1 аргумент2
java -cp out pr1.task6.Task6Harmonic
java -cp out pr1.task7.Task7Factorial
java -cp out pr2.author.TestAuthor
java -cp out pr2.ball.TestBall
java -cp out pr3.shapes.Main
java -cp out pr3.movable.Main
java -cp out pr4.task1.Main
java -cp out pr4.task2.Main
java -cp out pr4.task3.Main
java -cp out pr4.task4.Main
```

Для ПР1 №4 и ПР4 задания №3 программы читают ввод из консоли. В интернет-магазине тестовая учетная запись: `user` / `password`. Каталоги `out/` и `.class` в Git добавлять не нужно.
